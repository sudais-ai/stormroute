# StormRoute frontend

Weather-aware truck routing UI (Spotter AI assessment). React + TypeScript + Vite + Tailwind CSS v4.

## Run

```powershell
cd frontend
npm install
npm run dev      # http://localhost:5173
```

Dev server proxies `/api/*` to the Django backend at http://localhost:8000.

See the repo root `docs/` for project status, phase plan, and verification logs.
